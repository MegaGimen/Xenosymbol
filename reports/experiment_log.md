# 实验决策记录

## 固定的研究问题

冻结接收者，优化发送者的离散消息；第一版只用末输出内容 token 在中间层的余弦距离与消息长度构造 RL 奖励。生成前状态和输出文本用于后处理，不加入奖励。

验收分两层：工程上完成真实 RL、状态留存、接收者冻结校验；效果上比较训练前后在留出指令上的长度、距离与组合目标。没有观察到收益时明确记录无收益，而不是宣布发现新语言。

## 2026-11-23：环境和试运行

- 最初 SSH 失败来自本会话的受限执行环境。用户开放网络后连接成功。
- 远端 GPU：RTX 6000 Ada 48GB；现有 NF4 27B 量化模型可用，无需删除任何模型。
- 模型实际配置是 Qwen3_5ForConditionalGeneration，64 层，hidden_size=5120。使用已有量化文件 `/workspace/model_nf4_native`，没有把目录展示名当作架构依据。
- LoRA rank=8，alpha=16，q_proj/v_proj，共 3,014,656 个可训练参数。独立加载/生成/反向传播探针成功，峰值显存约 17.2GiB。
- 运行 pilot-01 在聊天模板返回值类型处报错。接收者同输入不变量已通过；修复发送者模板处理为渲染文本后明确编码，未改奖励和数据。
- pilot-02：lambda=0.005，lr=3e-5，8 步，每步 4 个独立样本，验证集前 4 条。初始验证平均长度 13.25，平均逐条长度比 0.4533，末 token 距离 0.16479，目标值 0.23104。第 4 步验证值完全未变。此时尚无训练收益证据。
- 远端 7 项自动测试全部通过：结束符切分、截断标记、奖励、位置索引、leave-one-out baseline，以及枚举分布下的策略梯度与精确期望梯度比较。

## pilot-02 完成

- 8 步后验证末 token 距离 0.16479 → 0.11758；组合损失 0.23104 → 0.18883；消息平均长度 13.25 → 14.25。收益主要来自距离降低，不是进一步缩短。
- 4 条验证中的字面输出相同率从 0.75 变为 0.5；这是独立观测，不影响已固定的 RL 奖励。
- 训练后冻结接收者的参考状态逐元素最大误差 0，输出文本不变。
- 45 条保存的观测全部通过离线重新计算：位置索引、消息 ID、末/前状态距离、奖励均一致。两个 checkpoint 中的 64 个 adapter 张量都实际发生更新。
- 直接发送完整原文的平均长度是 27.75，组合损失为 0.13875；因此试验轮尚未超过“不压缩”的目标值。不能仅报告相对未训练发送者的改善。
- 独立 E5 embedding 分析共 44 条观测、12 个不同任务；无 embedding 截断。末状态与输出 embedding 相似度的 Pearson r=0.6984，前状态与 embedding 为 0.5684，前/末状态之间为 0.8351。重复观测不独立，不能将这些数字当成统计显著性或普遍结论。

## main-01 决策（测试集揭盲前）

- 从相同初始模型重启，学习率改为 1e-4；24 步、每步 4 个样本；验证扩为完整 8 条。
- 仍用 lambda=0.005、相同层位、相同训练指令与通用提示词，不因指标表现修改奖励。
- 只按验证目标选 checkpoint；结束后一次性评估 8 条未训练的测试指令，比较本轮初始与验证最优发送者。测试结果不用于本轮 checkpoint 选择。
- 模型实测前状态因果位置校验：从完整序列取出的 prompt 末位置，与仅输入 prompt 的单独前向状态，余弦距离为 0。
- 实际采样与训练 likelihood 核查：一个 3-action 样本上，逐 token log probability 最大误差 0.0000316；报告 BF16 cached/full forward 的数值差异，不声称所有序列逐比特相同。

后续结果必须追加实际观测，不能从预期推断。

## main-01 的截断失败与 main-02

- main-01 第 8 步在 8 条验证上的组合损失从 0.22939 降到 0.15463，末状态距离从 0.17251 降到 0.06213，平均消息长度从 11.375 增到 18.5。
- 第 11 步的一条中文蒸发任务，压缩消息导致接收者展开长解释，超过 192 个输出 token；程序保存 `truncated_receiver.pt` 并报错停止。该截断状态未用作奖励，测试集尚未执行。
- 不移除这条指令。main-02 保持数据、seed、学习率、奖励和层位不变，只把完整回复上限提高至 1024，从头重跑，避免将 warm start 冒充精确续训。
- 同时补上每步 latest checkpoint，保存 adapter、优化器、随机状态与训练顺序；完整 sender action IDs 从这一轮开始入日志。现有 `--adapter` 仍是重新初始化优化器的 warm start，不应当作精确恢复接口。
- 对 main-01 保存的同一条失败消息单独重放：前 192 个 token 完全一致，最终生成 216 个内容 token 并正常结束，修复通过真实失败样本验证。保存于 `runs/truncation-check/`。
- main-02 第 16 步验证：末状态距离 0.04105、平均消息 20.375 token、组合损失 0.14292；完整原文平均 28.375 token，组合损失 0.141875。此时已接近原文目标值，但还不能说超过原文。

## main-02 完成与最终测试

- 第 24 步验证组合损失 0.137969、末状态距离 0.041094、消息 19.375 token；根据验证集选择该 checkpoint。
- 独立测试：初始发送者的距离 0.169827、组合损失 0.267952、长度 19.625；RL 后为 0.067279、0.166654、19.875。
- 测试原文平均长度 31.875、组合损失 0.159375，仍略优于 RL 压缩消息。没有据此修改 lambda、重选 checkpoint 或训练测试案例。
- 测试消息仍以可读的自然语言、算式、代码为主，不能宣称不可读协议涌现。
- 主运行共 145 条观测通过完整离线审计；冻结接收者误差 0；7 项远端测试全部通过；主实验与后处理均正常退出。
- 独立 embedding 未截断任何文本。全部 144 条非恒等观测的末状态/embedding Pearson r=0.839717，前状态/embedding r=0.700534，前/末状态 r=0.854161。40 个任务存在重复观测，相关性仅作描述。
- 最终测试 8 条已经揭盲。后续修改需要新的最终测试集，不重复利用这些案例宣称泛化。
- 完整结果见 [first_experiment.md](first_experiment.md)。
