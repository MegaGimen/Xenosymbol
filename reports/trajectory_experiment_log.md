# 轨迹中途 user 消息重写：实验记录

用户要求：使用 agent 轨迹，在中途某条 user 消息之后，让发送者看到完整的此前上下文并重写这条消息。保持之前约定的末内容 token 中间层距离 + 长度目标。

## 数据与边界

- 数据：[NVIDIA Nemotron-Agentic-v1](https://huggingface.co/datasets/nvidia/Nemotron-Agentic-v1)，interactive_agent，合成工具交互轨迹，CC-BY-4.0，来源版本与全部 ID 见 `data/trajectories/manifest.json`。
- 首 256 条中 79 条满足“非首条 user、前文有工具返回、后接 assistant”的结构条件。未按模型输出或成功率筛选。
- 选 24 条不同轨迹，16/4/4 分组；每条仅一个切点。历史和工具定义全部保留，未来消息不进入输入。接收者原始输入约 3164–4037 token，当前 user 消息为 29–151 token。
- 本轮是静态前缀上的下一条 assistant 回复/工具调用生成，不执行工具、不模拟其后完整环境。
- 两路共享前缀/后缀 token 必须一致；保存完整输入 ID、context hash、两种状态与生成文本。
- 新增 4 项上下文测试（未来内容隔离、仅替换目标、sender 可见前文、禁止首条 user 切点），远端合计 11 项测试通过。

## trajectory-smoke-01

- 2 个 RL step、每步 2 个候选，使用验证集前 2 条，不启用最终测试。
- 长上下文真实反向传播成功，峰值约 22.88GiB；冻结接收者末状态最大误差 0。
- 生成前状态与仅输入前缀的独立前向状态余弦距离约 1.2e-7。
- lambda=0.005 时，初始验证末状态距离 0.084673、长度 33、组合损失 0.249673；2 步后贪心验证未变。
- 发现通用编码提示不够清楚，某条重写变成了 assistant 的回答而非 user 的消息。没有硬编码该案例，而是在通用提示中明确保留用户视角，并在会话记录之后再次说明“输出替换的 USER 消息，不要回答它”。
- 同历史空消息的两个距离为约 0.2606、0.1923；无关消息约 0.2841、0.2288。正确重写的距离更小，但旧 lambda 的长度成本使某条空消息总分更好。

## trajectory-main-01（最终测试揭盲前的固定设置）

- 从原始底座新建 LoRA，不续用短指令版或 smoke 的 adapter。
- 保留两项损失，lambda 调为 0.002，学习率 1e-4，16 step，每步 2 个候选，8 步验证一次。
- 使用全部 4 条验证，选最优 checkpoint 后才比较 4 条独立测试轨迹；不根据测试调整参数。
- 用户消息最多 96 token；接收者最多生成 1024 token，未正常结束仍报错保留证据。
- 同一历史和同一消息下的冻结、贪心 receiver 结果可以缓存复用。恒等输入与训练后冻结检查强制重新前向，不用缓存制造通过。
- 通用提示调整后，初始 4 条验证末状态距离 0.015817，平均消息长度 46.75，组合损失 0.109317。这是一个不同初始化条件下的重写偏差，不是相对于原文（距离为 0）的改善，也不能与旧提示条件混在一起计算 RL 收益。
- 泛化、语义相似度和效率结论均等待实际结果；本轮不以“出现不可读语言”为既成事实。
- 4 条验证的空消息和无关消息末状态距离分别为 0.186085、0.185838；正确重写基线为 0.015817，存在清楚的状态差异。前状态距离相应为 0.110571、0.051761、0.002993。
- 第 8 步验证：长度 46.75 → 45.5，距离 0.015817 → 0.020203，组合损失 0.109317 → 0.111203，尚未超过新基线。保留该轮，不只报告长度改善。

## 完成结果

- 第 16 步验证与第 8 步相同，没有胜过第 0 步。按验证规则选择初始化 checkpoint，未用测试重选模型。
- 测试原文平均 72 token，基线/选中版本平均 60 token，距离 0.067512，组合损失 0.187512；原文组合损失 0.144。没有宣称整体超越原文。
- 测试的取消订单例子实际利用历史提取 ORD1048，40 → 29 token，两路都生成完全相同的 cancel_order 调用。
- 另有 102 → 96 token 的复杂请求触及发送者上限，发生行为变化；保留这个失败，没有删除或修改其测试答案。
- 15 项测试通过、61 条观测通过审计，接收者冻结重算误差 0；主训练与后处理结束。
- 后处理摘要程序原先把测试数硬写为 eight，已改为实际样本数并重算报告；best_step=0 时明确说明同策略导致相同输出，零区间不是学习证据。
- 全部测试结果和具体例子见 [trajectory_experiment.md](trajectory_experiment.md)。此 4 条最终测试已经揭盲，后续调参不能再用它们作为新验收集。

## 测试后诊断：只改历史订单号

- 没有训练或改动编码提示词。保持取消订单例子的当前 user 消息不变，将历史内 4 处 ORD1048 替换为 CTX704219。
- 模型重写与原重写完全同形，只替换成新订单号；接收者也生成取消 CTX704219 的调用。旧订单号没有残留。
- 这是对上下文使用的单例干预证据，不是另一个独立泛化测试，不加入 4 条测试的指标。
